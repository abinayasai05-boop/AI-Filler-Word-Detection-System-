# 🤖 AI Filler Word Detection System

The **AI Filler Word Detection System** is a Python-based NLP project that identifies unnecessary filler words in written speech or conversation transcripts. It analyzes the input text, counts filler words, calculates their percentage, provides a fluency score, and gives suggestions for improving communication.

## 🚀 Features

- 🔍 Detects common filler words
- 📊 Counts the frequency of each filler word
- 📈 Calculates filler-word percentage
- ⭐ Generates a fluency score
- 🎨 Highlights detected filler words
- 📉 Displays filler-word frequency charts
- 💡 Provides communication improvement feedback
- 🖥️ Includes an interactive Google Colab interface
- 🔑 No API key required

## 🧠 Filler Words Detected

The system can identify words and phrases such as:

- `um`
- `uh`
- `er`
- `erm`
- `hmm`
- `like`
- `actually`
- `basically`
- `literally`
- `you know`
- `i mean`
- `sort of`
- `kind of`
- `well`
- `so`

## 📊 Fluency Score

The system calculates a score based on filler-word usage.

| Filler Percentage | Fluency |
|---|---|
| 0% | Excellent |
| 0–2% | Excellent |
| 2–4% | Good |
| 4–6% | Moderate |
| 6–10% | Needs Improvement |
| 10–15% | Poor |
| Above 15% | High Filler Usage |
